# NBA Analytics Power BI Dashboard

## Overview

The Power BI component of this project will provide an interactive dashboard for analyzing NBA team and player performance.

The dashboard will use the cleaned NBA dataset prepared through the SQL pipeline.

## Planned Dashboard Sections

### Team Performance

- Wins and losses
- Win percentage
- Home vs away performance
- Team scoring performance
- Conference standings

### Player Performance

- Points per game
- Rebounds
- Assists
- Field goal percentage
- Three-point percentage
- Player efficiency

### Game Analysis

- Points scored by teams
- Home vs away scoring
- Game results
- Season-wise performance

### Interactive Filters

The dashboard is planned to include filters for:

- Season
- Team
- Player
- Conference
- Game date
